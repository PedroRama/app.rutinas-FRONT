# 🏋️‍♀️ App Rutinas - Frontend

Este proyecto representa la interfaz de usuario de la **Aplicación de Rutinas**, una plataforma diseñada para gestionar rutinas de entrenamiento personalizadas, seguimiento de progreso y planificación semanal.

## 🚀 Tecnologías Utilizadas

- **HTML**
- **CSS**
- **TypeScript / JavaScript**
- 
## 📁 COMPONENTES
components/
├── boton-inicio/ # Boton para volver al inicio desde cualquier pantalla.
├── boton-usuario/ # Boton para ir al usuario desde cualquier pantalla.
├── crearRutina/ # Boton para ir a la pantalla en la cual crearemos las rutinas.
├── inicio/ # El incio/menu de la página.
├── login/ # Gestionar el inicioSesión.
├── misRutinas/ # Ver el listado de todas mis Rutinas creadas.
├── registro/ # Gestionar el registro.
├── rutinasFav # Ver el listado de todas mis Rutinas guardadas como favoritas.
└── usuario # Información del usuario. Se accede a través del boton-usuario.
